# ShapeDrawing — Option 2

A C# and SplashKit recreation of the Week 4 ShapeDrawing exercise, extended for
Option 2 of the Custom Project Specifications. The original Week 4 source
project was not present, so the app follows the tutorial in the included PDF.
The model, event loop, and renderer are in one .NET project; `make build` puts
the compiled app in the root `build/` folder.

## Option 2 scope

- Recreate the Week 4 tutorial's documented shape selection and drawing
  workflow. The original C# project was not supplied, so compare this app with
  the version used in class before treating it as an exact continuation.
- Add 3–10 randomly positioned, randomly colored houses with rectangle, circle,
  and line parts.
- Draw the student's first name as one selectable composite. Support keyboard
  movement, resizing, and random recoloring of the selected name.
- Rotate all displayed drawables by the same random angle. Rotate lines and
  rectangles about their centers; keep circles compatible with rotation; rotate
  houses and names as units.
- Submit source code, an unlisted demonstration video, and a UML report with a
  class diagram and a sequence diagram for either the name or rotation feature.

## Getting started

1. Review the Option 2 requirements and the starter design in `doc/`.
2. Make sure SplashKit's native library is installed using the course setup.
3. Run `make build` and `make test`.
4. Run `make run`. The app asks for a first name, then opens the drawing
   window. The compiled program files are placed in the root `build/` folder.

## Controls

- `R`, `C`, `L` choose rectangle, circle, or line; left-click to add.
- Right-click a drawable to select it; `Delete` removes it.
- `H` adds 3–10 random houses; `N` draws the entered first name.
- Right-click the name to select it; arrow keys move it, Page Up/Down resize
  it, and Space changes its color.
- `T` rotates all drawable objects by the same random angle; `Escape` closes
  the app.

## Make targets

With GNU Make and the .NET SDK installed, run `make help` to list targets,
`make build` to build the application, `make run` to launch it, `make test` to
run the model tests, or `make clean` to remove build output. If SplashKit's
native library is missing, install it with the course's `skm` setup in a
supported MSYS2 terminal.

## Personalization before submission

- The app prompts for the first name at launch; enter the name you intend to
  demonstrate.
- The Week 4 tutorial documents `R`, `C`, and `L` as shape keys; the extension
  uses `H`, `N`, and `T` for its new features.
- Add your name and student ID to the start of the demonstration video, as
  required by the assignment.
- Confirm the instructor check-in and Canvas submission requirements.
